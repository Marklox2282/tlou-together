What it doesЧто умеет

A MULTIPLAYER item appears right in the game's own main menu. Everything else happens in the game.Пункт MULTIPLAYER появляется прямо в главном меню игры. Всё остальное происходит в самой игре.

01

LobbyЛобби

Create a lobby, invite a Steam friend or share a code with a secret part. In 23 languages.Создайте лобби, пригласите друга из Steam или отправьте код с секретной частью. На 23 языках.

02

Your partnerНапарник

See your friend walk, run, crouch and aim — as the chapter's hero, the companion or a character of their choice.Друг ходит, бегает, приседает и целится — в облике героя главы, спутника или выбранного персонажа.

03

Shared fightsОбщие бои

Damage and kills are shared. Enemies notice both of you.Урон и убийства общие. Враги замечают вас обоих.

04

One storyОдин сюжет

Checkpoints follow the player who got further. Die together, restart together. Same difficulty.Чекпоинты подтягиваются за тем, кто прошёл дальше. Погибли — начинаете вместе. Сложность общая.

05

Never lostНе потеряетесь

Your partner is outlined through walls when far away. Go to them in one key.Далёкий напарник виден контуром сквозь стены. Перенестись к нему — одна клавиша.

06

Self-updatingОбновляется сам

New versions download at game start. Every update is signed and checked.Новые версии скачиваются при запуске игры. Каждое обновление подписано и проверяется.

InstallУстановка

One file, once. Both players need it.Один файл, один раз. Нужен обоим игрокам.

DownloadСкачайте

Get winmm.dll with the Download button above.Скачайте winmm.dll кнопкой «Скачать» вверху.

Put it next to the gameПоложите рядом с игрой

Steam → Library → The Last of Us Part I → Manage → Browse local files. Copy the file there.Steam → Библиотека → The Last of Us Part I → Управление → Просмотреть локальные файлы. Скопируйте файл туда.

PlayИграйте

Start the game. Main menu → MULTIPLAYER → Create lobby, send the code to your friend; they choose Join by code. When they're in, press Start game.Запустите игру. Главное меню → MULTIPLAYER → Создать лобби, отправьте код другу, он выбирает «Войти по коду». Когда он подключится — «Начать игру».

FAQ

Do both of us need the game?Игра нужна обоим?

Yes. Each player needs their own copy of The Last of Us Part I on Steam.Да. Каждому нужна своя копия The Last of Us Part I в Steam.

Does it change my saves?Мод меняет мои сохранения?

The mod doesn't touch save files, but loading your partner's checkpoint is a normal game load, so the game may autosave there. Back up your saves if you care about them.Мод не трогает файлы сохранений, но загрузка чекпоинта напарника — обычная загрузка игры, и игра может сделать там автосохранение. Если сохранения важны — сделайте копию.

The lobby can't be createdЛобби не создаётся

Steam must be online. A VPN or proxy can block Steam's lobby servers — try turning it off.Steam должен быть в сети. VPN или прокси могут мешать серверам лобби Steam — попробуйте их выключить.

A game update broke itПосле обновления игры мод не работает

The mod supports one game build at a time and switches itself off on others. Wait for a mod update — it arrives automatically.Мод поддерживает одну сборку игры и на других выключается сам. Дождитесь обновления мода — оно придёт автоматически.

How do I remove it?Как удалить?

Delete winmm.dll and the tlou-together.* files from the game folder.Удалите winmm.dll и файлы tlou-together.* из папки игры.
